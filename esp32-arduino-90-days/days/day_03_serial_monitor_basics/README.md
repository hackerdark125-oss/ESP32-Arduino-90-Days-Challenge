# Day 3: Serial Monitor basics

**Phase:** Phase 1: Foundations (Days 1-14)
**Goal:** Print values with Serial.begin(115200) and Serial.println

## What I learned
-Learned how to use the Arduino Serial Monitor.

Understood how Serial.begin(9600) starts serial communication.

Learned to print text and values using Serial.println().

Understood how to check program output directly from the Arduino IDE.

Learned the importance of baud rate and matching it with the Serial Monitor.

## Parts used
-ESP32 development board

USB cable

Computer with Arduino IDE

## Wiring / pins
-Connected ESP32 to the computer using a USB cable.

No external wiring required.

## Problems and fixes
-Made sure the correct COM port and ESP32 board were selected.

Set the Serial Monitor baud rate to 115200 to match the code.

## Result
Successfully uploaded the program and displayed text and values in the Serial Monitor.
