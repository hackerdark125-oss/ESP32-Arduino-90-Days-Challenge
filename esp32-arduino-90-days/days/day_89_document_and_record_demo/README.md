# Day 89: Document and record the demo

**Goal:** Prepare a reproducible project README and a short hardware demonstration.

## Demo recording checklist
1. Show the ESP32 board and OLED wiring.
2. Power on and show the title screen.
3. Start the game and demonstrate left/right controls.
4. Show obstacles, score changes and collision/game-over behavior.
5. Show high-score persistence after a restart, if integrated.
6. Record a clear 30–90 second video with readable screen output.

## Documentation checklist
- Hardware list and exact board variant
- Wiring table and pin numbers
- Arduino IDE and ESP32 core version
- Required libraries and versions
- Upload instructions
- Controls and gameplay
- Known limitations and bugs
- Actual test results and media link

Do not state that a feature works or that a frame rate was achieved unless it was physically tested. Add your own video URL after recording.
