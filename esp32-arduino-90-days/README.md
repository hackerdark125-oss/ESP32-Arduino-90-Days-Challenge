# ESP32 Arduino: 90 Days of Learning

A daily learning journal and code collection for learning the ESP32 with the Arduino framework in 90 days, from blinking an LED to building a racing game.

## How to use this repo
1. Do one day per folder in `days/`.
2. Each folder has an Arduino sketch (`.ino`) and a `README.md` for notes.
3. Fill in the day's README after finishing, then tick it off in [PROGRESS.md](PROGRESS.md).
4. Commit daily: `git commit -m "Day 12: serial commands"`.

## Hardware
- ESP32 WROOM-32 DevKit board
- Breadboard, jumper wires, LEDs, resistors, push buttons
- Sensors added over time (see [docs/parts-list.md](docs/parts-list.md))

## Roadmap
See [ROADMAP.md](ROADMAP.md) for all 90 days.

## Structure
```
days/          one folder per day (sketch + notes)
docs/          setup, pinout and parts guides
projects/      bigger projects that grow out of the daily work
PROGRESS.md    daily checklist
ROADMAP.md     full 90-day plan
```

## Tools
Arduino IDE 2.x, ESP32 board package by Espressif, and libraries as each day requires.
